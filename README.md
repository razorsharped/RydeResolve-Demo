# RydeResolve narrated demo

[Watch the public demo video](https://razorsharped.github.io/RydeResolve-Demo/)

A 7 minute 30 second walkthrough covering the project overview, core agents, usage, build approach, and development-tool tips. English subtitles are burned into the video. Separate SRT/VTT subtitles and a transcript are included.

[Try the live project](https://ryderesolve-five.vercel.app/)

The current deployment uses simulated AI responses and illustrative evidence; backend checks and audit recording execute. Live model integrations require configuration. Genuine CodeBuddy/WorkBuddy development evidence must be submitted separately.

This public repository contains only demo presentation assets, not the private application source or credentials.
